# 🫒 نظام كشوفات المستودع — ALMEFLEH

نظام إدارة مستودع متكامل — Full-Stack: سندات إدخال/إخراج، كشوفات زباين أسبوعية،
قائمة أسعار، تحليل رسايل واتساب وصور السندات بالذكاء الاصطناعي، ومزامنة لحظية
بين كل الأجهزة.

## 🏗️ المعمارية — ٣ طبقات (زي qjo-ai بالضبط)

```
┌─────────────────┐   ┌──────────────────────┐   ┌─────────────────┐
│  الواجهة        │   │  الباك إند           │   │  فايربيس         │
│  public/        │──▶│  server.js (Express) │   │  Firestore DB    │
│  SPA ملف واحد   │   │  • بروكسي AI آمن —   │   │  • مزامنة لحظية  │
│  • IndexedDB    │   │    المفاتيح بالسيرفر │   │  • Auth مجهول    │
│  • تشتغل بلا نت │   │  • rate limit + CORS │   │  • قواعد أمان    │
└─────────────────┘   │  • تقديم public/     │   └────────▲────────┘
   Render Static      └──────────────────────┘            │
      (فورية، ما بتنام)      Render Web Service      HTTPS/WebSocket
                                  (مجاني)   ◀────────────┘
                                البيانات تتحرك مباشرة بين الواجهة وفايربيس —
                                الباك إند بيتدخّل بس لطلبات الذكاء الاصطناعي
```

**ليش هاد التقسيم؟** البيانات (سندات/أسعار/كشوفات) مجرّبة ومستقرة على Firestore
بمزامنة لحظية — السيرفر ما بلزمها. السيرفر بيحل مشكلة وحدة حقيقية:
**مفاتيح AI ما تظل مكشوفة بمتصفحات المستخدمين** — بتنتقل لمتغيرات بيئة برندر.

## 🚀 النشر على Render (مرة وحدة)

1. ارفع الريبو على GitHub
2. Render → **New → Blueprint** → اختار الريبو
   → `render.yaml` بيخلق **خدمتين** تلقائيًا: `mefleh-warehouse` (واجهة) و `mefleh-warehouse-api` (باك إند)
3. بخدمة **الـ API**: Environment → عبّي `AI_GROQ_KEY` (والباقي لو موجودات)
4. بفايربيس: **Authentication → Settings → Authorised domains** → أضف دومين الواجهة
5. **ربط الواجهة بالباك إند:** افتح `public/index.html` ودوّر `AI_PROXY`:
   ```js
   const AI_PROXY = { url:'https://mefleh-warehouse-api.onrender.com', token:'' };
   ```
   واحفظ وادفع — بتصير مفاتيح AI من السيرفر، ومش لازم تدخلها بأي متصفح أبدًا 🎉

> 💡 الباك إند المجاني برندر بينام بعد ١٥ دقيقة خمول — أول طلب AI بصحّيه
> (نص دقيقة تقريبًا) والباقي طبيعي. الواجهة Static فما بتنام أبدًا.

## 🔀 نموذج التزامن والتعارض (v20.1)

- **السجلات** (سندات/كشوفات/رسايل/إشعارات/طلبات/سلة/زباين الدفتر): **دمج بالمعاملة**
  — جهازان أضافا بنفس اللحظة = الاثنان يبقيان، وتعديلك لنفس السجل يكسب محليًا.
  الحذف المقصود يُحترم فورًا (شواهد حذف داخلية). لو حذفت سجلًا وجهازٌ آخر كان
  طافيًا أيامها، قد «يرجع» لما يشتغل — احذفه مرة ثانية (تصميم مقصود:
  الرجوع الآمن أفضل من ضياع سند بصمت).
- **الإعدادات والأصناف وسجل العمليات**: آخر كاتب يكسب (تتغير نادرًا ومن جهاز واحد غالبًا).
- **بدون إنترنت**: كل حفظ ينتظر بصندوق بريد محلي ويندفع تلقائيًا عند عودة الاتصال،
  مع ٨ محاولات اتصال متكررة كل ١٥ ثانية عند الإقلاع.

## 🔌 واجهات الباك إند

| المسار | الوصف |
|---|---|
| `GET /api/health` | نبضة حياة `{ok:true}` |
| `GET /api/ai/status` | أي مزوّدين مُعدّين — **بدون كشف مفاتيح** |
| `POST /api/ai/:provider` | بروكسي chat completions (groq/qwen/kimi) |

الحماية: توكن `x-ai-token` اختياري (`AI_PROXY_TOKEN`) + حد 40 طلب/5د لكل IP
+ تقييد CORS عبر `ALLOWED_ORIGINS` + تحقق من صيغة الجسم وتحديد `max_tokens`.

## 🔐 الأمان

- كلمات سر الموظفين: SHA-256 + salt، تُدار من داخل النظام (ما لها علاقة بفايربيس)
- قواعد Firestore: `request.auth != null` فقط — النشر: `npm run deploy:rules`
- مفاتيح AI وكلمات السر الظاهرة لا تُرفع للسحابة (مستثناة برمجيًا من المزامنة)
- نسخة احتياطية JSON يومية من داخل النظام — خزّنها دوريًا

> ✅ بدون تعبئة `AI_PROXY` النظام يظل يعمل 100% بوضع «مفاتيح المتصفح» القديم —
> الباك إند إضافة اختيارية، مش شرط تشغيل.
