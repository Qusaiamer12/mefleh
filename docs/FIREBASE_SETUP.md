# ☁️ ربط نظام المستودع بفايربيس — خطوة بخطوة (١٠ دقايق)

النظام صار جاهز للمزامنة السحابية. ضايل عليك خطوة وحدة: تعمل مشروع فايربيس مجاني وتعبّي الإعدادات جوّا الملف. كل شي تحت مجاني (خطة Spark — بتكفيكم بمراحل: 50 ألف قراءة و20 ألف كتابة باليوم).

---

## 1️⃣ إنشاء المشروع

1. افتح: <https://console.firebase.google.com>
2. **Add project / إنشاء مشروع** → الاسم: `المستودع` (أو أي اسم)
3. عطل Google Analytics (مش محتاجينه) → **Create project**

## 2️⃣ تفعيل قاعدة البيانات (Firestore)

1. من القائمة اليسار: **Build → Firestore Database**
2. **Create database**
3. اختار **Start in production mode**
4. الموقع: اختار أقرب منطقة (`me-central1` الدوحة إن وُجدت، أو أي منطقة أوروبا) → **Enable**

## 3️⃣ قواعد الأمان (مهم!)

1. بصفحة Firestore افتح تبويب **Rules**
2. امسح الموجود والصق:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /wh_sync/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```

3. **Publish**

## 4️⃣ التوثيق المجهول (Anonymous)

> **الفكرة:** شاشة دخول نظامك (قصي/عمار/…) تظل كما هي 100% ولا علاقة لها بفايربيس.
> التوثيق المجهول هو «بطاقة زائر» يأخذها المتصفح تلقائيًا أول ما يفتح الموقع —
> بلا إيميل ولا كلمة سر ولا أي حقل — عشان قاعدة البيانات (التي تحميها القواعد
> في الخطوة 3) تقبل الطلبات. بدون هذه الخطوة تبقى المزامنة مطفأة.

**أ) التفعيل:**
1. **Build → Authentication** → أول مرة: زر **Get started**
2. تبويب **Sign-in method**
3. اضغط **Anonymous** من قائمة الـ providers (أو **Add new provider**)
4. فعّل مفتاح **Enable** → **Save**
5. النتيجة المطلوبة: حالة Anonymous = **Enabled** ✅

**ب) إضافة دومين موقعك:**
1. **Build → Authentication →** تبويب **Settings**
2. صندوق **Authorised domains** → زر **Add domain**
3. اكتب دومين رندر (مثال: `almefleh-warehouse.onrender.com`) → **Add**

> 💡 دومين رندر تعرفه فقط بعد إنشاء الـ Static Site — ارجع لهذه النقطة بعد النشر.
> و`localhost` موجود جاهزًا، أي التجربة من جهازك مباشرة ستعمل فورًا.
>
> 🔍 **فحص ذاتي لاحقًا:** بعد النشر افتح الموقع — الشارة تصبح `☁️ متصل` خضراء،
> وفي **Authentication → Users** يظهر سطر `(anonymous)` تلقائيًا.
> نسيان إضافة الدومين يسبب خطأ `auth/unauthorized-domain` في كونسول المتصفح (F12).

## 5️⃣ إحضار الإعدادات (الخطوة الأخيرة بالكونسول)

1. اضغط ⚙️ **Project settings** (فوق يسار)
2. انزل لتحت عند **Your apps** → اضغط أيقونة **`</>`** (Web)
3. اسم التطبيق: `المستودع` → **Register app** (ما تحتاج Firebase Hosting)
4. بيطلعلك كود فيه `firebaseConfig` — انسخ القيم

## 6️⃣ اللصق بالملف

افتح `index.html` ودوّر عند أول سطر:

```js
const FIREBASE_CONFIG = {
  apiKey:            "PASTE_API_KEY_HERE",
  authDomain:        "PASTE_PROJECT.firebaseapp.com",
  projectId:         "PASTE_PROJECT_ID",
  storageBucket:     "PASTE_PROJECT.appspot.com",
  messagingSenderId: "PASTE_SENDER_ID",
  appId:             "PASTE_APP_ID"
};
```

عبّي القيم اللي نسختها (انسخها كتلة وبدّل الكتلة كلها). احفظ الملف.

## 7️⃣ النشر والزرع التلقائي

1. ارفع الملف المحدّث على GitHub → رندر بيحدّث الموقع تلقائيًا
2. **افتح الموقع أول مرة من جهازك الرئيسي اللي عليه البيانات الحالية** → النظام بيزرع السحابة لحاله (بالكونسول بيطبع: «☁️ زرعنا السحابة من هذا الجهاز»)
3. أي جهاز/موبايل ثاني يفتح الموقع: بيسحب البيانات تلقائيًا ✨ ومن هون ورايح **أي حفظ بأي جهاز بيظهر لحظيًا بالباقي**

---

## كيف بتعرف إنه شغال؟ (شارة الحالة)

جنب مؤشر الإنترنت فوق بيطلع مؤشر جديد:

| الشارة | المعنى |
|---|---|
| `☁️ متصل` (أخضر) | المزامنة شغالة تمام |
| `☁️ بيتصل…` | لحظات أول فتح للصفحة |
| `☁️ محلي` | لسا ما عبّيت الإعدادات — النظام شغال محلي 100% |
| `☁️ انقطع — شغال محلي` | مشكلة نت/إعداد — شغلك محفوظ محلي وبيرتفع لما يرجع |

## ملاحظات أمان وخصوصية

- ✅ كلمات سر الدخول مخزّنة مشفّرة (hash) وحتى النسخة «الظاهرة للمدير» **ما بتنرفع للسحابة** — بتضل على جهازك
- ✅ مفاتيح التحليل الذكي (Groq/…) **ما بتنرفع** — بتدخلها يدوي بكل جهاز مرة وحدة
- ✅ التخزين المحلي ضل شغال: النظام بيفتح فوري وبيكمّل شغل حتى لو النت قطع، وبيزامن لما يرجع
- ⚠️ آخر جهاز يحفّظ «بيكسب» لو جهازين عدّلوا نفس الشغلة بنفس اللحظة (نادر عمليًا بفريق صغير)
- 🔒 خزّن نسخة احتياطية JSON من الإعدادات كل فترة — عادة حلوة مهما كان

## مشاكل شائعة

| المشكلة | الحل |
|---|---|
| `auth/unauthorized-domain` بالكونسول | خطوة 4.3 — أضف دومين رندر لـ Authorized domains |
| `Missing or insufficient permissions` | خطوة 3 — تأكد إنك لصقت القواعد وعملت Publish |
| الشارة «محلي» رغم التعبئة | تأكد ما نسيت `PASTE` بأي خانة |
| جهاز جديد فتح قبل جهازك الرئيسي | بيسحب سحابة فاضية — سكّره، افتح الرئيسي أول مرة، بعدين ريفرش عالجديد |
