# 📱 قواعد تسجيل جروبات الواتساب

مرجع لقارئ الشات (`tools/wa-reader.js`) ولأي حدا بيسجّل من الجروبات.
مستخلصة من مقارنة جروب «تحميل اسلام» مع كشف اسلام المسجّل (أيلول 2026).
**ما فيها أسعار ولا بيانات زباين.**

## الأساسيات
- **كل جروب = زبون واحد بالنظام** (اسلام / بلال / عمار / سعد).
  الأسماء بأول الرسالة (ابو ينال، القرية، بسام، الحفاظ…) هي أطراف عند الزبون، **مش زباين بالنظام**.
- **التاريخ = تاريخ الرسالة.** سند واحد لكل يوم ولكل اتجاه (مثل الكشف).
- **الاتجاه:** كل رسالة إخراج، إلا إذا فيها:
  «ادخال / دخول / وصل / استلمنا / **مرتجع / مرتحع / ارجاع** / رجع».
- «بدون فاتورة» و«ذمم» **بتنسجّل عادي**، والكلمة بس معلومة.

## صيغة البند
| المكتوب | المعنى |
|---|---|
| `بيبي سطل ١٠١ ١٠ك` | بيبي 10ك × 101 |
| `135جلط10ك` | جلط 10ك × 135 |
| `٢ محشي جزر ٥ ك` | محشي جزر 5ك × 2 |
| `سلطه فلفل 9*4ك` | سلطة فلفل 4ك × 9 |
| `بيبي سطل ٣` (بلا حجم) | الحجم الافتراضي للصنف (السطل غالبًا 10ك، والزهرة 8ك، والمكسيكي 7ك) |
| `جزر ٢٠٠ كيلو` | جزر 10ك × 20 (الوزن الكلي مقسوم على العبوة) |
| `جزر ٢٦كيلو` | جزر 26ك × 1، والسعر محسوب بالكيلو |
| `نصوحي ٢كيلو ونص` | 2.5ك × 1 |
| `مشرح المفلح ٩٣٦٠ك` | 9.360ك (فاصلة الآلاف ضايعة) |
| `خيار بيبي قناني ٥٠حبة ١لتر` | بيبي 1لتر × 50 |
| `جاط مربع ٥٠٠٠تالاف` | جاط × 5000 |

## السعر
- **من قائمة الأسعار دايمًا** (سعر الإدخال غير سعر الإخراج).
- **إلا إذا الرسالة فيها سعر صريح**، وقتها بينسجل للبند هاد بس:
  `شيري مخلي ٢٠ ٨ك ١٩دينار` · `محشي جزر ٢٥ ١٠ك ١٦ونص` · `جلط ٢ ١٠ك / على ١٧`.
- رسالة فيها رقم بس (`١٣ ونص`، `٢٣ وربع`) هي سعر بلا صنف، وما بتنسجل.
- «بونص» = بضاعة مجانية مع الفاتورة. بتنسجل مع تنبيه، والسعر بيتأكد يدويًا.

**حالات بدها انتباه يدوي (ما انضافت كقاعدة تلقائية):**
- «سلطه فلفل … سوبر» انسجلت «سوبر سلطة هلابينو» بسعرها.
- «عين جمل» انسجلت مرة «جلط».
- «اخضر سطل» (بلا نوع) انسجل مرة «نصوحي».
- «مكدوس سوبر ٦ كراتين ٤ك» انسجل 24 (الكرتون = 4 مرطبانات 4ك)، و«كرتون ٢ك» = 6 مرطبانات.
- «جامبو اسود 13*20ك+8ك» انسجل وزن كلي (268ك × 1).

## الصور (أهم نقطة)
- **أغلب الإخراج موجود بصور الفواتير** (`<image omitted>`)، مش بالنص.
  لهيك التصدير لازم يكون **مع الوسائط (Attach Media)**، والصور بتنقرا يدويًا.
- **«بدون ال جرجير» تحت صورة** = سجّل فاتورة الصورة **بدون** هالصنف.
  ما بتمسح شي من الرسايل النصية.
- **«+ خيار اول ٢ ١٠ك» مع صورة** = بند إضافي على فاتورة الصورة، وبينسجل.
- تعليق بلا رقم («هلابينو بلدي»، «ال اول بيبي») = ملاحظة على الصورة.

## سير العمل
1. تصدير الجروب (مع الوسائط) → `node tools/wa-reader.js parse chat.zip --customer اسلام --backup نسخة.json`
2. مراجعة `review.md`: البنود ⚠️، والأسطر اللي ما انقرت، وقائمة الصور حسب اليوم.
3. تعديل `import.json` (إضافة بنود الصور + التصحيحات).
4. بالنظام: **الإعدادات ← 📥 استيراد سندات جاهزة**. الملف بيضيف سندات بس، وبتنعلّم 🟡 لحد المراجعة.
